# Fox Cherry Hunt

A fun 2D platformer game built with Godot Engine where the player controls a fox and races against time to collect cherries before the countdown ends.

## Game Objective

Collect 8 cherries within 60 seconds to win the game.  
If the timer reaches 0 before collecting all cherries, the player loses.

## Features

- Smooth fox movement and jumping
- Cherry collection system
- Countdown timer
- Win and lose conditions
- Sound effects
- Pixel-art style gameplay

## Controls

| Key | Action |
|------|--------|
| A / Left Arrow | Move Left |
| D / Right Arrow | Move Right |
| Space | Jump |

## Built With

- Godot Engine
- GDScript
